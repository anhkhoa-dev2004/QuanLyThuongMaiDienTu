HƯỚNG DẪN LÀM BÁO CÁO POWER BI
==============================

Power BI đọc file Excel do Python xuất ra. Số trên Power BI, trên phần mềm WinForms và trong file Python
dùng chung một cách tính, nên phải ra giống nhau.


BƯỚC 1. TẠO FILE EXCEL CHO POWER BI
-----------------------------------
1.1. Mở cửa sổ lệnh (cmd), vào thư mục PhanTich_Python:
       cd duong_dan\QuanLyThuongMaiDienTu\PhanTich_Python
1.2. Cài thư viện (chỉ làm 1 lần):
       pip install pandas openpyxl pyodbc
1.3. Chạy 1 trong 2 lệnh:
     - Đã chạy file SQL trong SSMS (khuyên dùng):
       python phan_tich_ban_hang.py --sqlserver "DRIVER={ODBC Driver 17 for SQL Server};SERVER=.\SQLPHANTAN1;DATABASE=QuanLyThuongMaiDienTu;Trusted_Connection=yes;"
     - Máy chưa có SQL Server, chỉ muốn chạy thử:
       python phan_tich_ban_hang.py --sqlfile ..\QuanLyThuongMaiDienTu_Database.sql
1.4. Màn hình hiện "Bước 1/12" đến "Bước 12/12", rồi in phần VIỆC CẦN LÀM.
1.5. Kết quả nằm trong thư mục PhanTich_Python\KetQua_PowerBI:
       DuLieu_PowerBI.xlsx   (mỗi trang tính là 1 bảng; trang DocTruoc giải thích từng bảng)
       các file .csv         (cùng nội dung, mở bằng Excel được)
       ViecCanLam.txt        (tóm tắt việc cần làm)


BƯỚC 2. ĐƯA DỮ LIỆU VÀO POWER BI
--------------------------------
2.1. Mở Power BI Desktop, chọn Blank report.
2.2. Bấm Get data > Excel workbook, chọn file KetQua_PowerBI\DuLieu_PowerBI.xlsx.
2.3. Đánh dấu các trang tính sau rồi bấm Load:
       BanHang, TienDonHang, Ngay, SanPham_BangDiem, KhachHang_Nhom, CamXuc_DanhGia, CamXuc_TraHang, TuKhachHayNoi,
       LyDoMua_TongHop, LyDoMua_ChiTiet, LyDoMua_TheoSanPham, MuaTheoHungSale, MuaChung, GioVang, KhoHang, LocDuLieu_NhatKy
2.4. Kiểm tra kiểu dữ liệu: bấm biểu tượng bảng (Table view) ở cạnh trái, chọn bảng KhachHang_Nhom,
     bấm cột SoDT_DaSua, ở ô Data type chọn Text (để giữ số 0 ở đầu số điện thoại).
     Làm tương tự với cột Ngay của bảng Ngay và bảng BanHang: Data type chọn Date.


BƯỚC 3. NỐI CÁC BẢNG
--------------------
3.1. Bấm biểu tượng sơ đồ (Model view) ở cạnh trái.
3.2. Power BI có thể đã tự nối vài đường. Xóa đường nào khác danh sách dưới đây (bấm vào đường, nhấn Delete).
3.3. Kéo cột bên trái thả lên cột bên phải để tạo đúng 7 đường nối sau (loại "Một - Nhiều", hướng lọc "Single"):
       Ngay[Ngay]              ->  BanHang[Ngay]
       Ngay[Ngay]              ->  TienDonHang[Ngay]
       SanPham_BangDiem[MaSP]  ->  BanHang[MaSP]
       SanPham_BangDiem[MaSP]  ->  CamXuc_DanhGia[MaSP]
       SanPham_BangDiem[MaSP]  ->  CamXuc_TraHang[MaSP]
       SanPham_BangDiem[MaSP]  ->  KhoHang[MaSP]
       KhachHang_Nhom[MaKH]    ->  BanHang[MaKH]
3.4. Chọn bảng Ngay, vào Table tools > Mark as date table, chọn cột Ngay.


BƯỚC 4. TẠO CÁC CON SỐ CẦN XEM
------------------------------
4.1. Chọn bảng BanHang ở khung Data bên phải.
4.2. Bấm Home > New measure, dán 1 dòng dưới đây, nhấn Enter. Lặp lại cho từng dòng.

Doanh thu = SUM(BanHang[DoanhThu])
Số đơn = CALCULATE(DISTINCTCOUNT(BanHang[MaDH]), BanHang[LaDonHuy] = "Không")
Đơn hủy = CALCULATE(DISTINCTCOUNT(BanHang[MaDH]), BanHang[LaDonHuy] = "Có")
% đơn hủy = DIVIDE([Đơn hủy], [Đơn hủy] + [Số đơn])
Giá trị 1 đơn = DIVIDE([Doanh thu], [Số đơn])
Lãi gộp = SUM(BanHang[LaiGop])
% lãi gộp = DIVIDE([Lãi gộp], [Doanh thu])
Doanh thu mỗi ngày sale = DIVIDE(CALCULATE([Doanh thu], Ngay[LaNgaySale] = "Có"), CALCULATE(COUNTROWS(Ngay), Ngay[LaNgaySale] = "Có"))
Doanh thu mỗi ngày thường = DIVIDE(CALCULATE([Doanh thu], Ngay[LaNgaySale] = "Không"), CALCULATE(COUNTROWS(Ngay), Ngay[LaNgaySale] = "Không"))
Ngày sale gấp mấy lần = DIVIDE([Doanh thu mỗi ngày sale], [Doanh thu mỗi ngày thường])
% doanh thu từ khách mua vì cảm xúc = DIVIDE(CALCULATE([Doanh thu], BanHang[KieuLyDoMua] = "Cảm xúc"), CALCULATE([Doanh thu], BanHang[KieuLyDoMua] <> "Chưa khảo sát"))

4.2b. Chọn bảng TienDonHang, tạo thêm (chỉ đơn đã giao mới có phí sàn và tiền thực nhận):

Phí sàn = SUM(TienDonHang[PhiSan])
Tiền hoàn khách = SUM(TienDonHang[TienHoanKhach])
Shop thực nhận = SUM(TienDonHang[TienShopNhan])
Lãi sau phí sàn = SUM(TienDonHang[LaiGop])
Tiền hàng đơn đã giao = CALCULATE(SUM(TienDonHang[TienHang]), TienDonHang[TrangThai] IN {"Đã giao", "Trả hàng/Hoàn tiền"})
% lãi sau phí sàn = DIVIDE([Lãi sau phí sàn], [Tiền hàng đơn đã giao])

4.3. Chọn bảng CamXuc_DanhGia, tạo thêm:

% khách hài lòng = DIVIDE(CALCULATE(COUNTROWS(CamXuc_DanhGia), CamXuc_DanhGia[SoSao] >= 4), COUNTROWS(CamXuc_DanhGia))
Đánh giá có lời chê = CALCULATE(COUNTROWS(CamXuc_DanhGia), CamXuc_DanhGia[CamXucTheoLoi] = "Chê")
Sao cao mà lời chê = CALCULATE(COUNTROWS(CamXuc_DanhGia), CamXuc_DanhGia[SaoCaoMaLoiChe] = "Có")

4.4. Chọn bảng LyDoMua_ChiTiet, tạo thêm:

% câu trả lời vì cảm xúc = DIVIDE(CALCULATE(COUNTROWS(LyDoMua_ChiTiet), LyDoMua_ChiTiet[KieuLyDoMua] = "Cảm xúc"), COUNTROWS(LyDoMua_ChiTiet))
Hào hứng trung bình = AVERAGE(LyDoMua_ChiTiet[MucHaoHung])

4.5. Định dạng: chọn từng con số ở khung Data, ở Measure tools chọn
       Doanh thu, Lãi gộp, Giá trị 1 đơn, Doanh thu mỗi ngày...: Whole number, bật dấu phẩy ngăn cách
       các con số bắt đầu bằng %: Percentage, 1 chữ số thập phân

Chạy bằng --sqlserver ngay sau khi chạy file SQL thì cũng phải ra các số này.
Số khác đi nghĩa là dữ liệu đã đổi (đã thêm đơn, sửa đơn trên phần mềm) hoặc bộ lọc đang bật.

Muốn biết từng con số lấy từ bảng nào, cột nào thì chạy file thứ hai:
       python nguon_so_lieu.py --sqlfile ..\QuanLyThuongMaiDienTu_Database.sql
File này in từng con số kèm cách tính và ghi "Khớp" / "KHÔNG KHỚP" so với các số ở trên.

Lưu ý: "Ngày sale gấp mấy lần" ở đây tính theo DOANH THU mỗi ngày. Màn "Bảng thông báo" trên WinForms (thủ tục
sp_BangThongBao_MuaTheoCamXuc) và trang MuaTheoHungSale tính theo SỐ CÁI bán mỗi ngày (ra 1,6 lần).
Hai con số đo 2 thứ khác nhau nên không cần bằng nhau.

Lưu ý về lãi: có 2 con số lãi, đo 2 thứ khác nhau.
  - "Lãi gộp" (bảng BanHang) = doanh thu - giá vốn (giá nhập bình quân), tính cho mọi đơn không hủy, CHƯA trừ phí sàn và tiền hoàn.
  - "Lãi sau phí sàn" (bảng TienDonHang) giống màn "Báo cáo doanh thu" trên WinForms: chỉ tính đơn đã giao;
    tiền shop thực nhận = tiền hàng - giảm giá của shop - phí sàn (bảng PhiSan) - tiền hoàn khách;
    lãi = tiền thực nhận - giá vốn, không tính giá vốn hàng khách trả còn bán được (hàng đó đã về lại kho).
  Phí sàn Shopee và TikTok lấy từ các bài viết có ghi nguồn trong bảng PhiSan (xem GHI_CHU_DU_LIEU_MO_PHONG.txt).
  Sau phí sàn, Shopee chỉ còn lãi khoảng 2,6% tiền hàng, TikTok 5,4%, cửa hàng 13,5% (xem ViecCanLam.txt).

Trạng thái đơn (cột TrangThai) theo đúng các bước của Shopee:
  Chờ xác nhận -> Chờ lấy hàng (đã xuất kho) -> Đang giao -> Đã giao;  Trả hàng/Hoàn tiền;  Đã hủy.
  Khách nhận tại cửa hàng thì xuất kho xong là Đã giao luôn (cột HinhThucNhan = "Nhận tại cửa hàng").
  Các đơn đặt sát mốc chốt 30/09/2026 còn đang dở: Chờ xác nhận, Chờ lấy hàng, Đang giao.


BƯỚC 7. CẬP NHẬT KHI CÓ ĐƠN MỚI
-------------------------------
7.1. Chạy lại lệnh ở bước 1.3 (file Excel cũ bị ghi đè; nhớ đóng file Excel trước khi chạy).
7.2. Trong Power BI bấm Home > Refresh.
